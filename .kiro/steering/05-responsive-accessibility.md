# Responsive and Accessibility Rules

Design intentionally for desktop, tablet and mobile. Do not merely shrink desktop layouts.

Mobile needs compact navigation, search, product grids, filter drawers, usable product galleries, checkout and order flows. Touch targets must be comfortable.

Desktop may use wider grids, filter sidebars and multi-column checkout.

Use semantic HTML, proper labels, keyboard navigation, visible focus, meaningful alt text, correct headings, accessible dialogs/drawers and sufficient contrast. Do not rely on color alone.

Forms must expose labels, validation, required/optional state, loading, success and errors.

Respect reduced motion.
