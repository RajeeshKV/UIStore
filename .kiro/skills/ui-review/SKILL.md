# UI Review Skill

Review every major page for:

- typography and hierarchy
- spacing and alignment
- image quality and proportions
- buttons, borders and shadows
- theme-token usage
- hover/focus/active/disabled/loading/error/empty states
- mobile/tablet/desktop behavior
- keyboard navigation and focus
- alt text and contrast
- reduced-motion behavior

Reject UI that is technically functional but visually inconsistent or unfinished.
