# Premium UI Skill

Build polished, premium ecommerce UI inspired by the supplied reference.

Process:
1. Identify the user goal.
2. Establish hierarchy.
3. Define desktop and mobile composition.
4. Define loading/empty/error/success states.
5. Reuse primitives and semantic theme tokens.
6. Add subtle interaction feedback.
7. Review visual consistency.

Avoid generic cards, excessive rounded containers, random gradients, heavy glassmorphism, excessive shadows and theatrical animation. A technically working page is not acceptable if it looks unfinished.
