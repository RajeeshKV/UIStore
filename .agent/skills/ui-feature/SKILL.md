# UI Feature Skill

Use this workflow when implementing a new frontend feature or screen.

## Workflow

1. Identify the exact route/page involved.
2. Inspect the existing page and its direct dependencies.
3. Search for similar existing components before creating anything new.
4. Reuse the existing design system, API client, state management, and form patterns.
5. Implement only the requested scope.
6. Add loading, error, empty, and success states where applicable.
7. Verify mobile, tablet, and desktop behavior.
8. Run targeted TypeScript/lint/build/tests as appropriate.
9. Report changed files and validation.

## Context Rule

Do not scan unrelated applications, backend projects, or unrelated feature areas.
