# UI Review Skill

Use this workflow when reviewing or improving an existing UI.

## Review Only What Matters

Inspect the requested screen and its direct components first.
Do not review the entire application unless explicitly requested.

## Check

- Visual hierarchy
- Spacing
- Typography
- Alignment
- Consistency with existing design system
- Responsive behavior
- Loading state
- Empty state
- Error state
- Form usability
- Button states
- Accessibility basics
- Mobile touch usability

## Rules

Do not introduce a redesign unless requested.
Do not modify unrelated screens.
Prefer existing components and tokens.
Explain significant UX changes before making broad changes.
