# Frontend Design Brief

## Reference

See `references/storefront-reference.png`. It is the primary visual inspiration.

## Target

A premium ecommerce storefront with black/white/neutral UI, colorful product imagery, modern typography, large editorial sections, smooth scrolling, subtle motion, skeleton loading and responsive desktop/mobile layouts.

## Home

Use a strong hero, trust/service highlights, category discovery, featured products, new arrivals, editorial promotion and a configurable footer. Avoid a repetitive banner-grid-banner-grid template feel.

## Catalog

Clean filter + product grid composition. Desktop sidebar is acceptable; mobile uses a filter sheet/drawer.

## Product

Large gallery and focused purchase panel with title, price, discount, variants, stock, delivery, quantity and purchase actions. Supporting details should be organized into clean sections/accordions.

## Cart/checkout

Minimal and trustworthy. Checkout should clearly show address, delivery, payment and backend-authoritative totals.

## Theme

Default is black/white/neutral. Customer palettes are configuration-driven. Product imagery remains colorful. Future logo-based palettes should be possible without component rewrites.

## Motion

Fast, subtle transitions: fade, small translate, scale, drawers, image hover and button feedback. Respect reduced motion.

## Standard

The result should look like a premium ecommerce agency deliverable, not a generic template.
