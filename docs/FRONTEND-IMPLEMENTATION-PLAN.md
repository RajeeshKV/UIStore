# Frontend Implementation Plan

## Phase A — Foundation

Set up Vite/React/TypeScript, Tailwind, theme tokens, customer theme configuration, layout, UI primitives, API client, error handling, skeleton system, motion utilities and responsive foundations.

## Phase B — Storefront Shell

Build header, footer, navigation, search, global store configuration, home composition and responsive shell.

## Phase C — Catalog

Build product listing, category/brand pages, search, filters, sorting, pagination, product cards and all loading/empty/error states.

## Phase D — Product

Build product detail, gallery, variants, pricing, availability, delivery and related products.

## Phase E — Cart and Checkout

Build cart drawer/page, addresses, delivery, coupon, checkout, Razorpay, COD and order confirmation.

## Phase F — Customer

Build login, registration, password reset, profile, addresses, orders and order details.

## Phase G — Admin

Build admin authentication, dashboard, products, categories, brands, inventory, orders, promotions, tax, settings, policies and customer management.

## Phase H — Production

Add/verify frontend Sentry, SEO, performance, accessibility, responsive behavior, error monitoring and deployment.

Do not implement all phases in one task. Each phase ends with build checks, functional checks and visual review.
